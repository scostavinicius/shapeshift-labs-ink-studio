# The night courier · sequence palette

Fit one 12-swatch palette for the arrival, courier close-up, and lantern
insert. The flame and the much rarer enamel glint each get a pinned slot.

```sh
node cli/ink-studio.js palette sequence examples/sequence-palette/courier.json --out courier-palette
```

Open `courier-palette/index.html`. Switch shots, try the 8-, 12-, 16-, and
24-swatch budgets, and click a swatch to see which materials use it. The policy
download reflects the selected budget.
